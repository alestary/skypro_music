# Skypro.Music

Учебное приложение музыкального сервиса на Next.js, React и TypeScript.

## Запуск локально

Требуется Node.js 20.9 или новее и npm.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

Для остановки сервера нажмите `Ctrl + C` в терминале.

## Проверки проекта

```bash
npm run lint
npm run typecheck
npm run build
```

## Реализованная функциональность домашнего задания

- Лайк/снятие лайка трека в списке и в нижнем аудиоплеере.
- Счётчик лайков, который обновляется после успешного ответа API.
- Избранное загружается с API и доступно по адресу `/favorites` только после авторизации.
- Удаление трека из избранного сразу обновляет список; при ошибке состояние откатывается и показывается сообщение.
- Access и refresh токены, а также имя пользователя сохраняются в LocalStorage после входа.
- Выход очищает данные сессии; после выхода пользователь возвращается на главную.
- `withReAuth` повторяет авторизованный запрос после ответа 401, предварительно обновляя access-токен через refresh-токен.
- `useMemo` используется для вычисления фильтров и списка треков; `useCallback` — для стабильных функций загрузки и изменения избранного.

API: https://webdev-music-003b5b991590.herokuapp.com
Документация API: https://github.com/Mielilon/skymusic_db/blob/main/README.md

## Проверка вручную

1. Запустите приложение и войдите в аккаунт.
2. На главной странице нажмите сердечко у трека: оно должно стать активным, а счётчик увеличиться.
3. Откройте «Избранное»: этот трек должен присутствовать.
4. Уберите трек из избранного: он должен исчезнуть со страницы.
5. Запустите трек и проверьте сердечко в нижнем плеере.
6. Обновите страницу: состояние избранного должно загрузиться с сервера.
7. Выйдите из аккаунта и попробуйте открыть `/favorites`: произойдёт переход на страницу входа.

Для проверки обновления токена дождитесь истечения access-токена (документация API указывает срок около 200 секунд), затем повторите действие, требующее авторизации.
