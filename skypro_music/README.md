# Skypro.Music

Учебный проект Skypro.Music на Next.js, React и TypeScript.

## Требования

- Node.js 20.9 или новее (рекомендуется актуальная LTS-версия).
- npm.

## Установка и запуск в Windows / VS Code

1. Распакуйте архив проекта в удобную папку.
2. Откройте в VS Code именно папку `skypro_music` — ту, в которой находятся `package.json`, `src` и `public`.
3. Откройте терминал VS Code: **Terminal → New Terminal**.
4. Установите зависимости:

   ```powershell
   npm install
   ```

5. Запустите приложение:

   ```powershell
   npm run dev
   ```

6. Откройте в браузере адрес `http://localhost:3000`.
7. Чтобы остановить сервер, нажмите `Ctrl + C` в терминале.

Если порт 3000 занят, Next.js предложит другой порт — откройте адрес, который будет показан в терминале.

## Проверка перед Pull Request

В терминале из корня проекта выполните:

```powershell
npm run lint
npx tsc --noEmit
npm run build
```

Все три команды должны завершиться без ошибок. Затем отдельно проверьте страницы `/`, `/signin` и `/signup` в браузере.

## Аудиоплеер (домашняя работа)

В проекте используется Redux Toolkit для хранения текущего трека и статуса воспроизведения. Нативный элемент `<audio>` скрыт, а управление им выполняется из компонента `Player` через `useRef`.

### Установка и запуск

Откройте терминал в папке `skypro_music` (там, где находится этот `package.json`) и выполните:

```bash
npm install
npm run dev
```

Затем откройте http://localhost:3000. Для остановки сервера нажмите `Ctrl + C` в терминале.

Для проверки перед отправкой PR выполните:

```bash
npm run lint
npm run build
```

### Логика плеера

- Нажатие на строку трека выбирает его в Redux и запускает воспроизведение.
- Кнопка Play/Pause управляет воспроизведением через `HTMLAudioElement`.
- Название и исполнитель выбранного трека отображаются в нижнем плеере.
- Точка у выбранного трека пульсирует только во время воспроизведения; на паузе она остаётся статичной.
- Перемотка, громкость, повтор и переходы между треками управляются через аудиоэлемент.

## Домашняя работа: фильтры, поиск и тесты

### Реализовано

- Комбинированная фильтрация по исполнителю, году выпуска и жанру. Несколько значений внутри одного фильтра объединяются по OR, разные фильтры — по AND.
- Списки значений фильтров вычисляются из полного каталога треков и не сужаются после применения других фильтров.
- Поиск учитывает начало названия трека, без учёта регистра и лишних пробелов.
- Сортировка по дате выпуска: по умолчанию (исходный порядок каталога), сначала новые, сначала старые. Треки с некорректной датой располагаются после треков с корректной датой.
- При отсутствии совпадений отображается сообщение «Нет подходящих треков».
- Состояние фильтров, поиска и сортировки хранится в странице каталога. При переходе на другой маршрут страница размонтируется, поэтому при возвращении состояние начинается с настроек по умолчанию.

### Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

### Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run test:coverage
npm run build
```

Тесты компонентов `SearchInput`, `TrackFilters`, `TrackSort` находятся рядом с компонентами. Тесты чистых функций фильтрации, сортировки и формирования вариантов фильтров находятся в `src/lib/trackFilters.test.ts`. Для чистых функций в конфигурации Vitest установлены пороги покрытия 100% по строкам, функциям, веткам и операторам.

Для установки тестовых зависимостей выполните `npm install` — команда синхронизирует `package-lock.json` с добавленными devDependencies.
