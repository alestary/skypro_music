# Skypro Music — домашняя работа

## Запуск проекта

Требуется Node.js 20.9 или новее (рекомендуется LTS).

1. Распакуйте архив.
2. Откройте терминал в папке `skypro_music` — там, где находится `package.json`.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите режим разработки:

   ```bash
   npm run dev
   ```

5. Откройте адрес, который появится в терминале (обычно http://localhost:3000).
6. Остановить сервер можно сочетанием `Ctrl + C`.

## Реализовано

- Открытие и закрытие меню через React state.
- Рендеринг треков из `src/data.ts` через `map`.
- Тип `Track` для моковых данных.
- Динамические уникальные списки исполнителей, годов выпуска и жанров.
- Одновременно открыт максимум один фильтр; повторный клик закрывает его.
- Активная категория выделяется цветом.
- Списки фильтров прокручиваются при переполнении.

Фильтрация треков намеренно не реализована: по условию этой домашней работы она не требуется.
