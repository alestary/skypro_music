# Skypro.Music — избранное и авторизация

## Реализовано

- Добавление и удаление треков из избранного из каталога и нижнего плеера.
- Синхронизация избранного с API (`GET favorite/all`, `POST favorite`, `DELETE favorite`).
- Счётчик отметок рядом с сердцем; оптимистичное обновление интерфейса с откатом при ошибке.
- Страница `/favorite` внутри общего `MusicShell` (Navigation, Sidebar, Player).
- Защита страницы избранного: гостевой пользователь перенаправляется на главную.
- Сохранение `access`, `refresh`, `username` и идентификатора пользователя в LocalStorage после входа.
- Очистка сессии при выходе; выход со страницы `/favorite` ведёт на главную.
- `withReAuth`: при 401 выполняется обновление access-токена через refresh-токен и один повтор исходного запроса. Параллельные 401 используют общий запрос обновления.
- `useMemo` и `useCallback` для вычисляемых данных и стабильных обработчиков.

## Запуск на Windows PowerShell

Откройте терминал в каталоге, где находится этот `package.json`, и выполните:

```powershell
npm ci
npm run dev
```

Откройте http://localhost:3000.

Для финальной проверки:

```powershell
npm run lint
npm run typecheck
npm run build
```

## Важно

Для авторизованных запросов используется API `https://webdev-music-003b5b991590.herokuapp.com`, описанный в README репозитория `Mielilon/skymusic_db`. Access-токен действует 200 секунд; refresh-запрос возвращает новый `access`.
